# Observability Dashboard

Сервис для управления заметками (Note), демонстрирующий production-подход
к наблюдаемости: сбор метрик, структурированные логи и визуализация в Grafana.

## Стек
- Java 21
- Spring Boot 3.x
- PostgreSQL
- Spring Boot Actuator + Micrometer
- Prometheus + Grafana
- Docker Compose
